# Known Issues

Project Silverfish Co-op is a proof of concept under active development. This list summarizes reports from release-candidate playtests. Check the notes for the specific ZIP you installed. Fixes verified in development can still need a live two-PC retest. [Release notes](https://github.com/hypnotoadtrance/silverfish-coop/releases)

## Current playtest checks

- **First bounty board press after travel.** `rc-2d4f6c9` keeps a brief in-memory board-open request for the same visit and local pawn while fresh party state arrives. The exact stock menu receipt still qualifies before the request runs. A regression test reproduced the lost press on the preceding build and verified one open after the same visit recovered, with refusal after expiry, a different visit, or a replacement pawn. In two muted Direct IP launches, the guest opened the Black Market board on the first staged press after arrival and settled both Dead Drops. The test recorded 61–128 ms from the test controller's Black Market press request to the verified menu. The same pair verified both Simmi jammer placements, guest destruction, both journals and shared payouts, weather travel, and the Crossroads door. It preserved the original saves. Ordinary Steam input and internet latency still need a two-PC retest. [Build source](https://github.com/hypnotoadtrance/silverfish-coop/commit/2d4f6c9c85453ee39080fd7efb6b5e3900d87999)

- **Randomized Dead Drop placement.** `rc-9c458ee` confirms placement, renewal, and retirement of the stock bag through the in-memory bridge. The guest receives the exact actor and pose while routine world publication stays on its own schedule. In two muted Direct IP launches from the candidate ZIP, the guest accepted the Crossroads and Metro contracts through the stock board, saw the host’s pose after the lease interval and reconnect, collected the corresponding bag using stock Interact, and turned in the same item for shared rewards of $300 and $600. Projection replies were 573–597 bytes and retirement replies were 453–481 bytes. Weather travel and the Crossroads door passed in the same pair. Turning in the contracts left the checkpoints untouched, and the original saves were preserved. An earlier run missed an immediate Black Market board press after travel, and the Metro test’s positioning fixture could not find sight of one placement. The passing run checked the board after the destination became ready and covered one placement per map. Retest natural approaches and immediate post-travel board interactions on Steam. [Build source](https://github.com/hypnotoadtrance/silverfish-coop/commit/9c458ee43bfddc489cb96c6065443b6788862985)

- **Guest vitals and equipped-weapon snapshots.** `rc-51bb19d` reuses the guest's verified save binding for routine status rows within the same observation. An unverified read uses the full qualification path, and gameplay commands qualify their target at execution. Comparing 256 reads per path on the exact ZIP produced the same pawn, save, and character. Full qualification took 41 ms in Observatory and 35 ms in Crossroads. Reusing the observation took 4 ms in each. Two muted Direct IP launches passed guest worn-slot and inventory changes, campfire damage, consumables, and Rusty Pistol fire and reload. A profile command timed out because the harness rejected its name. The corrected harness used two more launches on the same ZIP and passed weather travel, exit-wall checks, placeable pickups, shared cash, and the Crossroads door. Both pairs preserved the original saves. A Crossroads host gameplay-row pass still took 8.3 ms while the Lua heap dropped by about 4.9 MiB. Rendered frame pacing and Steam latency remain open. [Build source](https://github.com/hypnotoadtrance/silverfish-coop/commit/51bb19d8b199ebeb6ee9f32045c07f03f0d6ea41)

- **Snapshot contention and exit walls.** `rc-c729152` gives routine snapshots a lock independent of the local command and input queues. A focused native test published and read a snapshot while another thread held the command lock. Exit-wall permission changes reuse verified geometry. The wall still rechecks on expiry, travel, and replacement. In a synthetic comparison, 100 permission changes on two walls produced identical collision decisions and reduced entrance-tag reads from 200 to zero. In two muted Direct IP launches, the guest and separated host were blocked at the Observatory exit, then the regrouped party crossed. The same pair passed the cold crate, weather and siren, the Crossroads door, critter pickup, Lingering Teleport, mushrooms, and the Dock gate. Original saves were preserved. In this Crossroads run, the longer walking sample peaked at 21.5 ms on host and 12.3 ms on guest. An idle host sample still reached 32.3 ms with no timed co-op call in that interval. Rendered frame pacing and Steam interaction latency remain open. [Build source](https://github.com/hypnotoadtrance/silverfish-coop/commit/c729152867b019db2ad2f6f91d7e262ab814ed1b)
