# Native integration status

The staged Direct IP build has one host and one guest. The campaign store, guest catalog, and action channel are active in the two playtest maps and the qualified routes linking CrossRoads with DeadBridge and Cistern. See the [locked design](DESIGN.md) for release requirements.

| Area | Verified or implemented in the staged build | Work before campaign play |
| --- | --- | --- |
| Hosting and players | Authenticated Direct IP, guest-owned character selection, native replicated movement, reconnect and host restart | More than one guest, real-network validation, and Steam Invite |
| Combat and respawn | The C++ scope handles stock lethal damage for both paired pawns and provides in-place 10% revives. It vetoes stock damage between enrolled teammates. Native health is included in the co-op checkpoint. | Live coverage of the remaining weapon, NPC, and environmental producers, native HUD, and the full respawn flow |
| Loot and inventory | The host commits a qualified Bandage pickup once and applies it to the exact guest backpack. The wipe ledger retains or drops tracked items by GUID. A read-only stock weapon probe round-tripped the SMG's complete typed inventory value. | Native inventory UI and general pickup, use, equipment, and stacking. Trait-aware loot rolls and visual backpack actors |
| Wallet, shops, and quests | The authenticated guest can buy a native Bandage from qualified infinite merchant stock and turn in the stock Signal Jammer quest. The host credits quest cash once and records personal XP for every eligible character. | General NPC dialogue and merchant stock, other quests and reward types, and native guest XP projection |
| World and travel | The stock CrossRoads–DeadBridge exit works with a physical blocker and a 15-meter host gate. The stock CrossRoads–Cistern door uses its lock check, animation, and `CR_Cstrn` marker. Checkpoints and authenticated rejoins work after travel. | Remaining authored routes, host-driven item transports, native new-game setup, and world-state restoration and projection |

The cooked game uses the same game-instance save reference for both server-side pawns by default. A live probe moved the guest to a distinct transient SaveGame object and read 125 guest HP with the host still at 250 HP. Native inventory and dialog logic still calls the shared GameInstance or player/controller index zero. Replacing the save reference alone leaves those call sites shared.

The matched UE4SS v4.0.0 add-on can scope stock `Player_FP_C:Die` to the exact local host and enrolled guest pawns. Each player took scripted stock lethal damage and the other player revived them in place at 25 of 250 HP. A separate stock `DealDamage` canary returned zero damage and a nonlethal result for friendly fire. The original poison-gas actor downed the guest from 25 to −5 HP while the host stayed at 250 HP. Death notifications retain the pawn and scope identities during teardown. The guest fall trial did not produce a host-authoritative downed event. [Native build and lab instructions](../native/README.md)

The exit hook inspects the stock box overlap before it reaches `Prep_OpenNextLevel`. It checks the live player and roster, then sends an approved route through the co-op listen-server handoff. The native hook qualifies the authored destination and entrance tag against the staged build and puts the host on the matching destination Arrow before guests are admitted. The physical blocker uses a separate local shape so the authorized host can reach the original stock overlap.

The transition-door hook intercepts stock interaction before a guest can open the door or trigger its lock animation. For an eligible host the original lock and animation run. The delayed child exit checks the same host and party again before requesting travel. The staged route qualifies the CrossRoads–Cistern door and its destination child marker.

With native travel enabled, the item-use guard rejects Stardust and the green, blue, red, and golden cubes before stock activation. A scratch stock ItemManager verified the five pre-consumption guards on each peer. Guests receive `host_activation_required`. Hosts receive `coordinated_route_required` until a verified party-use transaction exists. The host transaction needs the actual inventory GUID, the stock destination and return policy, and one durable use charge. Stardust resolves a dream through `Find_DreamLevel`, blue uses the stored respawn level, red and green select among stock destination sets, and golden targets the Gold Nexus. Host travel through those items is pending.

The stock Silverfish build ships Unreal's Null subsystem. A Steam Invite test needs an authorized Steamworks integration under the game's App ID and two separately entitled Steam sessions for a real invite round-trip. The existing Direct IP path supports local two-process testing without Steam.
