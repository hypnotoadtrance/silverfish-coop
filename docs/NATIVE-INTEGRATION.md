# Native integration status

The staged Direct IP build supports an experimental native party of up to four guests. The largest verified loopback party was one host and two guests. The campaign store, guest catalog, and action channel also support the two playtest maps. See the [locked design](DESIGN.md) for release requirements.

| --- | --- | --- |

Three local instances exercised authenticated enrollment, retained both guest pawns through a reconnect, and checkpointed two distinct guest save generations. | Live coverage above two guests and across separate PCs. Steam Invite is deferred |
| Combat and respawn | The C++ scope intercepts stock lethal damage, vetoes friendly fire, and restores 10% health on revive. A guest fired a verified stock projectile. The stock Playtest Bandit saw the enrolled guest, selected that pawn in combat, and inflicted verified damage while the client rendered one simulated Bandit. The cooked game uses the same game-instance save reference for both server-side pawns by default. A live probe moved the guest to a distinct transient SaveGame object and read 125 guest HP with the host still at 250 HP. Native inventory and dialog logic still calls the shared GameInstance or player/controller index zero. Replacing the save reference alone leaves those call sites shared.

The matched UE4SS v4.0.0 add-on can scope stock `Player_FP_C:Die` to the exact local host and enrolled guest pawns. Each player took scripted stock lethal damage and the other player revived them in place at 25 of 250 HP. A separate stock `DealDamage` canary returned zero damage and a nonlethal result for friendly fire. The original poison-gas actor downed the guest from 25 to −5 HP while the host stayed at 250 HP. The native fall hook supplies measured gameplay time when the enrolled guest's disabled actor tick leaves the stock fall timer empty. The live guest landing downed only that pawn through the stock damage path. Death notifications retain the pawn and scope identities during teardown. [Native build and lab instructions](../native/README.md)

The exit hook inspects the stock box overlap before it reaches `Prep_OpenNextLevel`. It checks the live player and roster, then sends an approved route through the co-op listen-server handoff. The native hook qualifies the authored destination and entrance tag against the staged build and puts the host on the matching destination Arrow before guests are admitted. Each physical blocker uses a separate local shape so the authorized host can reach the original stock overlap. CrossRoads uses distinct shapes for its DeadBridge and Observatory exits, and the Observatory route lands at the stock `Obsv_Etr` marker in each direction.

The transition-door hook intercepts stock interaction before a guest can open the door or trigger its lock animation. For an eligible host the original lock and animation run. The delayed child exit checks the same host and party again before requesting travel. The staged route qualifies the CrossRoads–Cistern door and its destination child marker.

With native travel enabled, the pre-consumption guard makes both Dream Dust variants and all six cube types host-only. A scratch stock ItemManager verified all eight guest denials. In CrossRoads, the host can use an exact Golden Cube from the canonical backpack when the active party is within 15 meters. The host checkpoints the GUID and destination, debits the one item, and places the party at Gold Nexus's `PlayerStart_1`. Startup finishes a pending move before admitting guests. The three qualified Nexus exits that point to CrossRoads use the stock `Nexus_CrossRoads` arrival marker.

The loopback run covered rejection with the cube still in the backpack, consuming that same GUID through the stock inventory card's Use action after regrouping, reconnecting with the same character, restarting in Gold Nexus, and taking the stock exit back. A separate staged run interrupted the coordinator after the native debit and verified recovery from the committed receipt.

The Blue Cube reads the canonical host save's `RespawnLevel` and exact `Bed` ID. It can carry the party to the qualified Observatory or DeadBridge rest. An empty rest selection sends the party to the Observatory. The arrival uses the bed Arrow or the stock alternate spawn based on the host's faction reputation. When the alternate position intersects terrain, the mod keeps its horizontal coordinates and tries the nearest safe capsule height. If the party is already in the destination map, both players move without changing pawns or reconnecting. The campaign keeps the qualified rest ID and the cube receipts across restart. The loopback fixture sets the two stock rest fields directly. The native sleep flow and stock teleport event side effects still need campaign coverage.

With no active Tarot flag, a host Stardust use in CrossRoads transports the party to the stock Exchange `PlayerStart_1`. A denied use leaves the stack intact. An accepted use commits the GUID and decrements the stack by one. The stock countdown actor stays in place. The coordinator owns the 96-second return, including the stock startup and fade delays, and intercepts the actor's powered early-return signal. Both paths returned the same authenticated party to the Observatory fallback in staged loopback runs. The timer and in-flight stock stack remainder are recoverable from the campaign checkpoint.

The host selects the first active stock Tarot flag in the cooked priority order. One co-op checkpoint records the exact stack, variant, destination and rest point. Before opening the dream, a second checkpoint pairs the stock inventory debit, Tarot overwrite to −1 and native reputation award with a durable effects receipt. Paired runs covered Fruiting Stardust to Rook, timed Pyroclast, Black Ocean's 160-second timer, and return through Slate's exact stock overlap. Slate reconciles the guests' descent height near the terminal plane so the same three-dimensional 15-meter gate can still apply. Black Stone pickup return and uninterrupted chaining into Nothing remain open.

The Red Cube commits one uniform draw from the nine stock destinations. Each uses the exact authored `Red_Tes` marker. All nine arrivals, single debits, and selected return paths to CrossRoads passed solo staged checks. A two-player run denied use while the guest was out of range, took the regrouped party to Old Pipes, and restored the rolled map, guest character, and item debit after restart. Doors on the return paths continue through their stock interaction checks.

The Green Cube draws once from every destination the host's stock faction relationships allow. It places the party at the stock bed, reputation alternate, or PlayerStart for that map. All eight geometries and selected outbound routes passed isolated staged checks. The paired test used the live six-destination candidate set, drew Scientist Shop, and restored the same map, character, and single debit after restart.

The Purple Cube commits one uniform draw from 15 cooked destinations, including the current map when eligible. The arrival uses the exact stock bed or PlayerStart. A paired run drew Docks, placed the guest by the host, and recovered the same character and one-item debit after restart. Isolated live checks covered all 15 arrivals and the three stock outbound exits from Beach, Docks, and Refinery.

The Regression Matrix records a host anchor through the stock secondary input. Its primary input checks the party radius then charges the stock Eather source. A paired run exercised one same-map transfer and one cross-map return to the same anchor, each using 100 Eather from the same canister. The anchor, Matrix GUID, and the exact 800 Eather remaining survived restart. A separate interrupted paid transfer finished on startup without charging a second time.

The opt-in expanded exit registry contains 138 directed routes across 54 maps. It checks exact authored stock placements and uses the destination's entrance arrow. A paired run verified that the Cistern keypad rejected the wrong combination, opened the exact Sci Tunnel door for the correct combination, and blocked guest activation. Paired runs covered both directions of the CrossRoads–DeadBridge overlap and CrossRoads–Cistern transition door. Sweeps verified that the invisible wall blocks guests and a host whose party is out of range. The Scientist Shop locks and remaining catalog still need live coverage.

The Observatory rest command and stock sleep screen both use the exact SavePoint and stock day cycle. A host and two guests rested for one game hour, left via the CrossRoads exit, and returned to the saved Observatory bed after all three went down. All three recovered full native health. The stock sleep-screen run measured unchanged desktop cursor bounds across 1,305 samples. The rest catalog covers 11 cooked beds.

A connected guest rendered the host's directional light, sky material, fog, and clouds in CrossRoads while its local Unreal SaveGame stayed unchanged. Exact presentation profiles also cover Observatory, DeadBridge, and City. Cistern's cooked day controller only tracks time.

The extraction test used one retained row and a dropped backpack. The host froze both typed save generations, accepted the guest's selected SMG, and preserved its equipment index. It moved the nine-round reserve to a separate stock save generation tied to the guest and their death position. The host's recovery request was denied. The guest recovered all nine rounds once. These claims use the local action interface. An in-world backpack display and the stock selection UI still need integration.

Authored campaigns serialize the host's canonical stock `SaveGame_BP_C` into an isolated generation file during checkpoints and travel. The campaign record binds the file by map, size, and SHA-256. The previous campaign checkpoint keeps its own generation for recovery. On restart the launcher loads the stock object before opening the listen world and verifies that the host pawn adopts it. A two-player run recovered the exact Stardust GUID, remaining stack quantity, authenticated guest, and world seed. Pre-travel capture in CrossRoads verified the stock Antfarm and placed explosives flush.

The native guest ownership mode keeps a different stock save generation per character under the host campaign. Fresh guests receive stock SaveGame defaults and their own maximum health. The host binds the authenticated guest to the exact native connection before binding the detached save. The staged Bandage and native health survived travel, reconnect, and host restart in that character's own frame.

The stock Silverfish build ships Unreal's Null subsystem. A Steam Invite test needs an authorized Steamworks integration under the game's App ID and two separately entitled Steam sessions for a real invite round-trip. The existing Direct IP path supports local two-process testing without Steam.
