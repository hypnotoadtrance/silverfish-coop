# Native integration status

The staged Direct IP build supports an experimental native party of up to four guests. One host and four guests completed the loopback travel, Observatory sleep, and party wipe sequence. The campaign store, guest catalog, and action channel also support the two playtest maps. See the [locked design](DESIGN.md) for release requirements.

A same-PC Direct IP transport run used a non-loopback host-only interface and a selected UDP port. Four authenticated guests exchanged fragmented 12 KiB gameplay packets on separate routes. One guest reconnected on the same game-facing endpoints while another exchanged packets. Pausing gameplay forwarding for travel left control requests working. The run used UDP test endpoints in place of Unreal game instances.

A later two-game run used a selected UDP port on the local host-only adapter. The guest's movement replicated to the host, packet loss recovered automatically to the same stock pawn, and both authenticated characters travelled to the second playtest map. The same campaign and guest returned through the original invite after a same-port host restart, and all nine original save hashes matched. Both game processes ran on one PC.

In a two-player CrossRoads run, each peer attached the stock default body and head to the other player's native pawn. The visuals use the pawn's normal animation class and have collision disabled. Each peer reported one remote avatar and retained its first-person view. The host cleared the departed guest's avatar and both peers restored their remote avatars when the same guest character rejoined on a fresh pawn. The isolated guest took a PNG with offscreen rendering and mouse capture disabled. Local `status.json` reports model setup and any error under `game.native_player_avatars`. Per-character appearance and equipment cosmetics, including disguise outfits, remain open. [Offscreen avatar test](../tests/live_avatar_capture.py)

After the path came back, the guest authenticated automatically and regained the same stock CrossRoads pawn. The run also checked that the original single-player save hashes matched. The offline regression repeats the connection loss with the real Direct IP transport and campaign lease.
